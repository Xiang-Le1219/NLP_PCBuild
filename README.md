# PC Build Advisor using OPT

## Notebook-first workflow

This repository was generated by `notebooks/PCBuild_OPT_Preprocessing.ipynb`. The notebook extracted and cleaned all 25 source CSV categories, audited 166 source fields, and exported the preprocessed tables used by the Streamlit app.

## Run locally

Use Python 3.11. Install dependencies with `pip install -r requirements.txt`, then run `streamlit run app.py`. The app reads preprocessed data from `data/processed/engine/`; it does not need the original `csv.zip` at runtime.

## Model modes

- Rule-based baseline: deterministic regex, aliases, typo correction and catalogue-aware matching.
- Pretrained OPT-125M: base Hugging Face checkpoint.
- Fine-tuned OPT-125M: LoRA adapter in `adapters/extract_125m/`, when present.

## Data scope

All 25 categories are exported under `data/processed/catalog/`. The current build solver actively assembles configurations using 11 categories (CPU, GPU, motherboard, RAM, internal storage, PSU, case, cooler, monitor, keyboard and mouse). The other categories are retained and audited for future extensions.

## Results

See `results/model_comparison.csv`, `results/model_status.csv`, `results/compatibility_test.csv`, `results/catalog_cleaning_report.csv`, and the attribute audit CSV files. A model that was not executed is marked `Not evaluated`; no placeholder accuracy is reported as a real score.

## Price and compatibility limitations

Catalogue price conversion uses the project's fixed USD/MYR assumption, not live prices. Compatibility checks cover only the rules implemented in the prototype. Confirm prices, BIOS support, cooler mounting, GPU length and case clearance with manufacturers before purchase.
